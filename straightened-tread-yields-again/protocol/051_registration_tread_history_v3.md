This document and `051_registration_tread_history_v2.md` jointly form the frozen, pre-result protocol. It supersedes only the three clauses below. The v1 and v2 reviews remain preserved. The v2 review (`codex_051d_v2_gate.txt`) was MAJOR REVISION and exposed an analytic endpoint/scope contradiction. No registered result has been run.

1. **Diagnostic endpoint and immediate event.** The common actual nonlinear diagnostic endpoint is **1.35 P_y**, not 1.50 P_y. At this load the rectangular ideal-plastic virgin envelope predicts surface strain approximately `(f_y/E)*sqrt(0.5/(1.5−M(1.35P_y)/M_y))`, about 0.29%, below the 0.5% ceiling. All q branches must reach 1.35 P_y, and all scope checks apply at every actual load stage, not only the endpoint. If the post-history state at diagnostic P=0 has an outward-active yield surface (positive directional derivative, `|f|≤1e−8 f_y`) and an infinitesimal positive increment produces plastic strain, set `P_re=0` immediately. This is a failed release gate, not a root to discard. A tangent/inward surface contact is not an event. If an event cannot be bracketed below 1.35 P_y, mark the branch failed; do not extrapolate.

2. **Every-cell bow uncertainty before minimization.** Run the 51-cell primary baseline, then repeat **every one of the 51 q cells** with longitudinal resolution alone doubled, thickness nodes alone doubled, and load-step counts alone doubled. For each q, calculate its provisional operational bow uncertainty `u_B(q)=|B_Nx−B_base|+|B_Nz−B_base|+|B_steps−B_base|`. Reload-event bracketing has zero contribution to B because B is measured before reload; do not use it to shrink or enlarge bow uncertainty. Minimize B using the base values, but retain as co-minimum candidates every cell whose `[B_base−u_B,B_base+u_B]` interval overlaps the minimum cell's interval; if transitive overlaps connect more cells, include the full connected overlap component. None may be pruned with a global or sampled uncertainty estimate. At each retained candidate compute the event and its independent bracket refinement; each must meet both materiality gates. Also include immediate q neighbors of every candidate in all four refinements as the v2 rule requires, even if not co-minima. If q minimum is not stable within one grid interval, report a co-minimum range and require each cell to pass. All 51 cellwise bow uncertainties and event results are disclosed in the report.

3. **Sensitivities and compute ceiling.** For each of the six sensitivity legs, at fixed baseline-selected q_star or **all** co-minimum q cells, compute its own q=0 control denominator and repeat each tested q case and q=0 at doubled longitudinal stations alone, doubled fibre nodes alone, doubled load steps alone, and a tighter reload-event bracket alone. Form its own adverse bow and re-yield ratio bounds by the same summed-absolute-shift rule; no baseline error estimate may be reused as a sensitivity envelope. If the complete registered work cannot fit the v2 60-minute hard compute ceiling, profile/vectorize without altering the protocol or redesign and preserve the failure.
